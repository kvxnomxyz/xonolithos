# Xstore catalog

Catalog branch for **XonolithOS / xOS**. `main` is the OS project and `xstore` is the store
application source. Direct child folders contain `title.txt`, `author.txt`, and
`description.txt`; installation additionally requires `apk.txt`, `sha256.txt`, and `package.txt`.

These entries link to original publishers or F-Droid. APKs are not mirrored here.
Hashes refer to the exact versions selected for the first private tablet build.
The source and license fields link to publisher information; each app retains its own terms.
GCam and Bitpost integration are pending, so no speculative entries are published for them.

See the [catalog format](https://github.com/kvxnomxyz/xonolithos/blob/main/docs/XSTORE-CATALOG.md).
