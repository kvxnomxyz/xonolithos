# XonolithOS wiki

XonolithOS (**xOS**) is a community Android 17 fork based on LineageOS 24.0. The name **xOS** is case-sensitive. This wiki tracks build and device work; it is not a stable ROM release announcement.

- [[Devices]] — supported models and honest test status
- [[Build]] — source checkout and local build workflow
- [[Xstore]] — store app and `appstore` catalog format
- [[System-Center]] — verified update packs and developer controls
- [[Branding]] — logo, boot animation, and wallpapers
- [[Contributing]] — how to help

The canonical project source is [`main`](https://github.com/kvxnomxyz/xonolithos). Xstore's standalone source is on [`xstore`](https://github.com/kvxnomxyz/xonolithos/tree/xstore); catalog entries are on [`appstore`](https://github.com/kvxnomxyz/xonolithos/tree/appstore). xOS is independent and is not an official LineageOS release.
