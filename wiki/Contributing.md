# Contributing

Start with [CONTRIBUTING.md](https://github.com/kvxnomxyz/xonolithos/blob/main/CONTRIBUTING.md). Issues and pull requests should name the affected branch, exact device and build, observed behavior, and the test that was actually run. Remove secrets and personal information from logs.

Useful work includes Samsung hardware testing, lavender bring-up, accessibility, translations, artwork, Xstore catalog review, and documentation. A compile-only result should never be reported as a boot or hardware pass.

The project source is Apache-2.0 where original; upstream components keep their own licenses. See [NOTICE.md](https://github.com/kvxnomxyz/xonolithos/blob/main/NOTICE.md).
